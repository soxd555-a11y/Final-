QA Playbook (03)

White-box Testing, Coverage และ Cyclomatic Complexity

เข้าใจโค้ดฝั่งในเพื่อ design test ที่เข้มแข็ง — ต้องการทั้งความถูกต้องและ efficiency

1. Control Flow Graph (CFG)

วิธีวาด: แยก node (จุด/จำลอง) และ edge (เส้นเชื่อม) จากโค้ด พร้อม region (เขตของ decision)

ตัวอย่างโค้ดสั้น

src/adult.ts
export function isAdult(age: number): boolean {
  if (age >= 18) {
    return true;
  }
  return false;
}

CFG (แบบ SVG)

สรุปท่องจำ (Key Points)

  • Node = จุดเริ่ม/จุด decision/exit, Edge = transition
  • Region = เขตของ decision (true/false path)

2. Coverage ทุกชนิด

ลำดับความเข้มข้น: Statement < Branch < Condition < Decision/Condition < Multiple Condition < MC/DC < Path

Coverage typeนิยามสูตร
Statement Coveragestatement ทั้งหมด execute หรือไม่SC = (executed / total) × 100
Branch Coverageทุก branch true/false ของ decisionBC = (branches covered / total branches) × 100
Condition Coverageแต่ละ condition ของ decision มี true และ falseCC = (covered conditions / total conditions) × 100
Decision/Condition (DC)branch + condition รวมต้องการทั้ง decision และ condition
Multiple Condition (MC)ทดสอบ combination ทั้งหมดของ conditionsจำนวน test = 2^n
MC/DCทุก pair ของ conditions ส่งผลต่างกันแก้ compound condition (A && (B || C))
Path Coverageทุก path ใน CFG= จำนวน independent paths

ตัวอย่าง MC/DC — A && (B || C)

Primitive conditions: A, B, C → MC/DC ต้องทดสอบ pair (A,B) และ (A,C) ที่ส่งผลต่างกัน

3. Cyclomatic Complexity

3 สูตรหลัก — ต้องคำนวณซ้ำแล้วเทียบกันทุกครั้ง

สูตรคำอธิบาย
V(G) = E − N + 2Pจำนวน edge (E), node (N), component (P)
V(G) = จำนวน decision nodes + 1V = (# predicates) + 1
V(G) = จำนวน regionsจำนวน path ใน CFG

ตัวอย่างคำนวณที่ตรวจแล้วทั้งสองสูตร (ให้ค่าตรงกัน)

ตัวอย่าง checkDiscount(age) — function ที่มี 2 predicates:

src/discount.ts
export function checkDiscount(age: number): number {
  if (age < 18) {
    return 0;
  }
  if (age > 60) {
    return 0;
  }
  return 10;
}

คำนวณที่ 1: decision nodes = 2 → V(G) = 2 + 1 = 3

คำนวณที่ 2: V(G) = E − N + 2 = 5 − 4 + 2 = 3 ให้ทั้งสองสูตรให้ค่าตรงกัน

สรุปท่องจำ (Key Points)

  • สูตร E−N+2 ใช้กับ CFG graph; สูตร decision+1 ใช้กับ structured code
  • ทั้งสองต้องให้ค่าตรงกันเมื่อคำนวณจากโค้มเดียวกัน

4. Basis Path Testing

ขั้นตอน

  1. หา independent paths จาก V(G)
  2. สร้าง test case ให้ครบทุก independent path
  3. ใช้ expected results จาก business rules

สรุปท่องจำ (Key Points)

  • Basis paths = minimal set ของ independent paths
  • การออกแบบได้ branch coverage 100% เมื่อ paths ครบ

5. ตัวอย่างโจทย์ฝึก + เฉลย (≥3 ข้อ)

แต่ละข้อ: โค้ด → CFG → V(G) → ออกแบบ test case → branch coverage 100%

โจทย์ที่ 1 — หาเกรด (Grade)

src/grade.ts
export function grade(score: number): string {
  if (score >= 90) return 'A';
  if (score >= 80) return 'B';
  if (score >= 70) return 'C';
  return 'F';
}

Predicates = 3 → V(G) = 4

Independent paths: score >= 90 → A; score >= 80 → B; score >= 70 → C; score < 70 → F (4 paths)

TestInputExpected
T1score = 95A
T2score = 85B
T3score = 75C
T4score = 60F

Branch coverage: ทดสอบครบทุก branch → coverage = 100%

โจทย์ที่ 2 — ตรวจ Leap Year

src/leap.ts
export function isLeap(year: number): boolean {
  if (year % 4 !== 0) return false;
  if (year % 100 !== 0) return true;
  if (year % 400 !== 0) return false;
  return true;
}

Predicates = 3 → V(G) = 4; paths: (2024 → true), (2023 → false), (1900 → false), (2000 → true)

โจทย์ที่ 3 — Login Check

src/login.ts
export function loginOk(user: string, pass: string): boolean {
  if (user === 'admin' && pass === 'secret') return true;
  if (user.length < 3) return false;
  return false;
}

MC/DC กับ compound condition: จำนวน primitive conditions = 3 (user === 'admin', pass === 'secret', user.length > 3) → V(G) = 4

สรุปท่องจำ (Key Points)

  • ทุกโจทย์ฝึกให้ V(G) ทุกสูตร (decision+1, regions) ให้ค่าตรงกัน
  • branch coverage 100% มักเป็นสิ่งตั้งต้นของ basis path test

6. Mutation Testing

Mutant = การแก้ไขเล็กน้อยในโค้ด; Killed = test ที่ทำให้ mutant fail; Mutation score = killed / total

สรุปท่องจำ (Key Points)

  • Mutation score ยิ่งสูง (≈100%) แสดงว่า tests ยังจับ bug ได้ดี
  • Mutation testing ใช้ compute มาก → ใช้กับ critical path เท่านั้นใน CI
