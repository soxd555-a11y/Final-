Playwright Recipes

1. ทดสอบ Login (data-driven)

โจทย์: ทดสอบ login สำเร็จ / รหัสผ่านผิด / ช่องว่าง บน https://www.saucedemo.com

tests/login.spec.ts
import { test, expect } from '@playwright/test';

test.describe('Login', () => {
  const users = [
    { username: 'standard_user', password: 'secret_sauce', valid: true },
    { username: 'standard_user', password: 'wrong', valid: false },
  ];

  for (const u of users) {
    test(`login - ${u.username} - ${u.valid ? 'valid' : 'invalid'}`, async ({ page }) => {
      await page.goto('https://www.saucedemo.com');
      await page.getByPlaceholder('Username').fill(u.username);
      await page.getByPlaceholder('Password').fill(u.password);
      await page.getByRole('button', { name: /login/i }).click();

      if (u.valid) {
        await expect(page).toHaveURL(/inventory/);
      } else {
        await expect(page.getByText('Username and password do not match')).toBeVisible();
      }
    });
  }
});

สรุปท่องจำ (Key Points)

  • ใช้ array + for...of ทำ data-driven test
  • ช่องว่าง: ใช้ fill('') หรือ clear() ก่อนกรอก

2. ทดสอบ TodoMVC

โจทย์: เพิ่ม / ทำเครื่องหมายเสร็จ / แก้ไข / ลบ / filter บน https://demo.playwright.dev/todomvc

tests/todomvc.spec.ts
import { test, expect } from '@playwright/test';

test('TodoMVC add / complete / edit / delete / filter', async ({ page }) => {
  await page.goto('https://demo.playwright.dev/todomvc');
  const input = page.getByPlaceholder('What needs to be done?');

  await input.fill('Buy milk');
  await input.press('Enter');
  await expect(page.getByRole('listitem').filter({ hasText: 'Buy milk' })).toHaveCount(1);

  const item = page.getByRole('listitem').filter({ hasText: 'Buy milk' });
  await item.getByRole('checkbox').check();
  await expect(item).toHaveClass(/completed/);

  await item.getByContent('Buy milk').dblclick();
  await item.getByRole('textbox').fill('Buy oat milk');
  await item.keyboard.press('Enter');
  await expect(page.getByText('Buy oat milk')).toHaveCount(1);

  await page.getByRole('button', { name: 'Delete' }).click();
  await expect(page.getByText('Buy oat milk')).toHaveCount(0);

  await page.getByRole('button', { name: 'Active' }).click();
  await expect(page.getByRole('listitem')).toHaveCount(0);
});

3. ทดสอบ Form Validation

โจทย์: ช่องว่าง / อีเมลผิดรูปแบบ / ขอบเขต BVA ของตัวเลข — เชื่อมกับเทคนิคใน test-design.html

tests/form.spec.ts
import { test, expect } from '@playwright/test';

test('signup form validation', async ({ page }) => {
  await page.goto('https://example.com/signup');

  // 1. ช่องว่าง
  await page.getByRole('button', { name: 'Submit' }).click();
  await expect(page.getByText('กรุณากรอกข้อมูลให้ครบถ้วน')).toBeVisible();

  // 2. อีเมลผิดรูปแบบ
  await page.getByLabel('Email').fill('not-an-email');
  await page.getByRole('button', { name: 'Submit' }).click();
  await expect(page.getByText('รูปแบบอีเมลไม่ถูกต้อง')).toBeVisible();

  // 3. BVA: ตัวเลขอย่างอายุ 17 / 18 / 19 / 59 / 60 / 61
  for (const age of [17, 18, 19, 59, 60, 61]) {
    await page.getByLabel('Age').fill(String(age));
    await page.getByRole('button', { name: 'Submit' }).click();
    const ok = age >= 18 && age <= 60;
    await expect(page.getByRole('alert')).toHaveText(ok ? 'ok' : 'invalid');
  }
});

7. ทดสอบ File Upload / Download

โจทย์: upload file / download file

tests/files.spec.ts
import { test, expect } from '@playwright/test';

test('upload and download', async ({ page }) => {
  await page.goto('https://demo.playwright.dev/upload');

  const fileChooserPromise = page.waitForEvent('filechooser');
  await page.getByLabel('Upload file').click();
  const fileChooser = await fileChooserPromise;
  await fileChooser.setFiles('/path/to/report.pdf');

  const downloadPromise = page.waitForEvent('download');
  await page.getByRole('button', { name: 'Download' }).click();
  const download = await downloadPromise;
  await download.saveAs('/tmp/report.pdf');
});

8. ทดสอบ Alert / Confirm / Prompt Dialog

โจทย์: จัดการ dialog

tests/dialogs.spec.ts
import { test, expect } from '@playwright/test';

test('alert / confirm / prompt', async ({ page }) => {
  page.on('dialog', async (dialog) => {
    if (dialog.type() === 'alert') {
      await dialog.accept();
    } else if (dialog.type() === 'confirm') {
      await dialog.accept();
    } else if (dialog.type() === 'prompt') {
      await dialog.accept('my answer');
    }
  });

  await page.goto('https://demo.playwright.dev/dialog');
  await page.getByRole('button', { name: 'Alert' }).click();
  await page.getByRole('button', { name: 'Confirm' }).click();
  await page.getByRole('button', { name: 'Prompt' }).click();
});

9. ทดสอบหลายแท็บ / Popup / iframe

โจทย์: เปิดแท็บใหม่ / popup / iframe

tests/multipage.spec.ts
import { test, expect } from '@playwright/test';

test('new tab and iframe', async ({ page }) => {
  await page.goto('https://demo.playwright.dev/tabs');

  const popupPromise = context.waitForEvent('page');
  const context = page.context();
  // หรือ: const [popup] = await Promise.all([context.waitForEvent('page'), page.getByRole('button', { name: 'Open tab' }).click()]);
  const popup = await popupPromise;
  await popup.waitForLoadState('domcontentloaded');

  const frame = page.frameLocator('iframe#frame');
  await frame.getByRole('heading', { name: 'Inside frame' }).waitFor();
});

11. API Test CRUD + API + UI รวมกัน

โจทย์: CRUD กับ public API (jsonplaceholder) และผสม API + UI

tests/api.spec.ts
import { test, expect } from '@playwright/test';

test('API CRUD on jsonplaceholder', async ({ request }) => {
  const create = await request.post('https://jsonplaceholder.typicode.com/posts', { data: { title: 'T', body: 'B', userId: 1 } });
  expect(create.ok()).toBeTruthy();
  const created = await create.json();
  const get = await request.get(`/posts/${created.id}`);
  expect((await get.json()).title).toBe('T');
  const del = await request.delete(`/posts/${created.id}`);
  expect(del.status()).toBe(200);
});

test('API + UI: create todo via API then verify in UI', async ({ page, request }) => {
  const api = await request.post('https://api.example.com/todos', { data: { title: 'Write spec' } });
  const todo = await api.json();
  await page.goto('https://demo.playwright.dev/todomvc');
  await page.getByPlaceholder('What needs to be done?').fill(todo.title);
  await page.keyboard.press('Enter');
  await expect(page.getByRole('listitem').filter({ hasText: todo.title })).toHaveCount(1);
});

12. Mock API Response และจำลอง Error 500

โจทย์: mock response / จำลง error 500 แล้วตรวจ UI แสดง error

tests/mock.spec.ts
import { test, expect } from '@playwright/test';

test.beforeEach(async ({ page }) => {
  await page.route('**/api/**', async (route) => {
    if (route.request().url().includes('/api/orders')) {
      await route.fulfill({ status: 500, body: JSON.stringify({ error: 'server error' }) });
    } else {
      await route.continue();
    }
  });
});

test('UI shows error on API 500', async ({ page }) => {
  await page.goto('https://demo.playwright.dev/checkout');
  await page.getByRole('button', { name: 'Submit' }).click();
  await expect(page.getByRole('alert')).toContainText('เชื่อมต่อไม่สำเร็จ');
});

16. Wait Strategies

โจทย์: เมื่อไหร่ใช้ waitForSelector, waitForURL, waitForResponse, waitForLoadState — เทียบกับ auto-wait

tests/waiting.spec.ts
import { test, expect } from '@playwright/test';

test('wait strategies', async ({ page }) => {
  await page.goto('https://demo.playwright.dev');
  await page.waitForSelector('#content');          // เวลาเฉพาะ เรื่อว element
  await page.waitForURL('**/some-page');         // เวลาเฉพาะ เรื่อว URL
  const apiPromise = page.waitForResponse('**/api/user');
  await page.getByRole('button', { name: 'Load' }).click();
  const response = await apiPromise;
  expect(response.status()).toBe(200);

  await page.waitForLoadState('networkidle');
});

สรุปท่องจำ (Key Points)

  • Default: web-first assertions ทำ auto-wait — ไม่ต้อง manual wait
  • ใช้ waitFor* เฉพาะต่อกรณีที่ต้องการความแม่นยำสูง

ปรับสูตรให้เข้ากับโจทย์สอบ
