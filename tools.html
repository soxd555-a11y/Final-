QA Playbook (07)

เครื่องมือคำนวณ / สร้างอัตโนมัติ

เครื่องมือ client-side ทำงานผ่าน assets/tools.js (pure functions) — ตรวจ input ก่อนคำนวณ

1. BVA Generator

กรอก min, max → ได้ค่าทดสอบแบบ 2-value, 3-value, robust

2. EP Helper

กรอกช่วง valid (min–max) → แสดง class: invalid ต่ำกว่า / valid / invalid สูงกว่า

3. Decision Table Generator

กรอกจำนวน condition (1–5) และชื่อ → สร้างตารางครบทุก rule (2^n) แล้วเว้นช่อง action ให้กรอกเอง

4. Cyclomatic Complexity Calculator

โหมด A: กรอก E, N, P → ได้ V(G); โหมด B: กรอกจำนวน decision nodes → V(G) = d + 1

5. Coverage Calculator

กรอก executed / total → ได้ % (statement/branch/condition เลือก label ได้)

6. Test Case Template Generator

กรอก ID/Title/Steps/Expected → สร้างแถว Markdown table พร้อมปุ่ม copy

7. Bug Report Generator

กรอกช่อง → สร้างข้อความ bug report พร้อม copy

8. Playwright Test Skeleton Generator

กรอก URL, ชื่อเทสต์, เลือก action พื้นฐาน → สร้างโค้ด .spec.ts โครงเริ่มต้นพร้อม copy

สรุปท่องจำ (Key Points)

  • ตรวจ input ก่อนคำนวณ — แสดง error ที่เข้าใจง่าย
  • BVA(18,60) → ได้ 17,18,19,59,60,61
