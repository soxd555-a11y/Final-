Quick Start Playwright 5 นาที

คำสั่งเรียงลำดับตั้งแต่ติดตั้งถึงเปิด report — ใช้ได้กับ Node.js 22+

terminal
npm init playwright@latest
npx playwright install
npx playwright test
npx playwright show-report
