QA Playbook (08)

Troubleshooting Playwright

รูปแบบ: อาการ → สาเหตุ → วิธีแก้ (common errors)

1. Executable doesn't exist ... playwright install

อาการ

Error: Executable doesn't exist ... playwright install

สาเหตุ

Browser binary ยังไม่ได้ download

วิธีแก้

terminal
npx playwright install
npx playwright install --with-deps

2. Timeout 30000ms exceeded

อาการ

Locator ผิด / element ไม่โหลด / โหลดช้า

สาเหตุ

Selector ไม่ตรง หรือ page โหลดช้า

วิธีแก้

tests/x.spec.ts
await page.getByRole('button', { name: 'Login' }).click({ timeout: 10000 });
// หรือใช้ waitForURL / waitForSelector

3. strict mode violation: locator resolved to N elements

อาการ

Test 失敗ด้วย strict mode violation

สาเหตุ

Locator เดียวกัน match หลาย element

วิธีแก้

tests/x.spec.ts
await page.getByRole('button', { name: 'Submit' }).first().click();
await page.getByText('Save').filter({ hasText: 'primary' }).click();

4. Error: expect(received).toBeVisible() failed

อาการ

Element ยังไม่เห็นในขณะที่รอ

สาเหตุ

Auto-wait หมายเหตุ timeout (default 5s)

วิธีแก้

เช็ก locator ให้แน่ใจว่า selector ถูกต้อง และไม่มี iframe ซ่อน

5. page.goto: net::ERR_CONNECTION_REFUSED

อาการ

Server ยังไม่รัน / หรือ webServer config ไม่ถูก

วิธีแก้

playwright.config.ts
webServer: { command: 'npm run start', url: 'http://localhost:3000', reuseExistingServer: !process.env.CI }

6. Test timeout vs Expect timeout

อาการ

Test timeout 30000ms vs expect timeout 5000ms ต่างกันอย่างไร

วิธีแก้

ตั้งแต่ละตัวตามหน้าที่; ใช้ timeout ใน config / assertion

7. Test ผ่านในเครื่อง แต่ตกบน CI

อาการ

Flaky test

สาเหตุ

เวลา, ข้อมูลร่วม, viewport

วิธีแก้

แยก data, ใช้ web-first assertion, ห้าม sleep

8. element ถูกบัง / element is not stable / intercepts pointer events

อาการ

click ไม่สำเร็จ เพราะ element ลำดับชั้น / animation

วิธีแก้

ใช้ scrollIntoViewIfNeeded, หยุด animation หรือใช้ force

9. iframe หา element ไม่เจอ

อาการ

Locator ไม่เจอ element ใน iframe

วิธีแก้

ใช้ frameLocator

10. Cannot find module '@playwright/test'

อาการ

ModuleNotFound

วิธีแก้

terminal
npm install -D @playwright/test
npx playwright install

11. TypeError: ... is not a function จาก await หายไป

อาการ

Typo ในชื่อ function / ลืม await

วิธีแก้

ตรวจชื่อ API ตรงกับ docs (เช่น page.locator(...) ไม่ใช่ locator(...))

12. login state ไม่คงอยู่

อาการ

Test ที่ต้องการ login ทุกครั้ง fail

วิธีแก้

ใช้ storageState จาก global setup

13. toHaveScreenshot ไม่ตรงบนเครื่องอื่น

อาการ

Visual regression fail บน CI / OS ต่าง

วิธีแก้

terminal
npx playwright test --update-snapshots

14. Port ถูกใช้ / browser ไม่เปิดบน Linux

อาการ

Port conflict / missing system deps

วิธีแก้

terminal
npx playwright install --with-deps
# เปลี่ยน port: webServer.url เป็น port อื่น

15. npx playwright test แล้วไม่พบเทสต์

อาการ

0 tests found

วิธีแก้

ชื่อไฟล์ต้องลงท้าย .spec.ts และอยู่ใน testDir

16. API test ได้ 403/401

อาการ

API request ไม่ได้รับอนุญาต

วิธีแก้

ส่ง headers/token/UA ที่เหมาะสมใน request

สรุปท่องจำ (Key Points)

  • รูปแบบ อาการ → สาเหตุ → วิธีแก้ คือแนวทางแก้ไข
  • ทุก error ควรมีวิธีแก้ที่เจาะจง
