Glossary / ศัพท์เทคนิก

ศัพท์ไทย–อังกฤษพร้อมคำอธิบายสั้น (เรียงตามตัวอักษร A–Z)

ศัพท์ที่เกี่ยวข้อง

ศัพท์คำอธิบาย
Acceptance Testingการทดสอบเพื่อยอมรับระบบตามความต้องการผู้ใช้
Accessibilityการทำให้ส่วนประสงค์เข้าถึงได้ (WCAG)
Agileกระบวนการพัฒนาแบบ iterative
APIApplication Programming Interface
Assertionการตรวจสอบค่าที่คาดหวังใน test
Automated Testingการทดสอบด้วย script/automation
BDDBehavior-Driven Development — Given-When-Then
Black-boxทดสอบโดยไม่ดู internal implementation
Boundary Valueค่าขอบ (boundary) ของ input range
BugDefect ที่พบใน product
CI/CDContinuous Integration / Continuous Delivery
Coverageวัดจำนวน code/test ที่ถูกครอบคลุม
Defectปัญหาที่สร้างขึ้นใน product จาก error
DevOpsการบูรณาการ development/operations
Exploratory Testingการทดสอบแบบไม่เปิด test case ก่อน
Errorความผิดพลาดชั่วคราวใน process/ระบบ
ETExploratory Testing
Failureการทำงานที่ผิดจากที่คาด (runtime)
Flaky TestTest ที่ผ่าน/ล้มเหลวแปรปรวน
Functional Testingทดสอบ feature ตาม requirement
Gherkinโครง BDD: Feature/Scenario/Given-When-Then
Given-When-Thenรูปแบบการเขียน behavior test
Hybrid Testingผสม black-box + white-box
Integration Testingทดสอบ module ที่เชื่อมกัน
ISTQBInternational Software Testing Qualifications Board
Key Pointสรุปข้อสำคัญของ section
Locatorsการค้นหา element ใน DOM
Mutation Testingทดสอบว่า test จับ bug ได้ดีขึ้น
Non-functionalPerformance/Load/Stress/Security/Usability
Pairwiseการทดสอบทุกคูณบรรลุคู่
PlaywrightE2E testing framework
Regressionทดสอบซ้ำหลัง change
Retestingทดสอบซ้ำของ defect ที่ fix
Sanityการตรวจสอบความพร้อมของ build
SDLCSoftware Development Life Cycle
Smokeการตรวจ smoke ของ build
State Transitionการทดสอบ state machine
Stakeholderผู้มีส่วนได้ร่วม
Test Caseรายการการทดสอบที่กำหนดไว้
Test Planแผนการทดสอบ
Test PyramidUnit > Integration > E2E
Test Strategyแนวทางการทดสอบ
Test Suiteชุด test ที่รันด้วยกัน
Traceบันทึกการทำ test
UATUser Acceptance Testing
White-boxทดสอบโดยดู internal code
Workflowกระบวนการ/ขั้นตอนทำงาน
